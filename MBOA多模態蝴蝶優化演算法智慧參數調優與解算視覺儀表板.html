MODULE 01｜生物物理感應與空間初始化

蝴蝶香氣場強度模型與佳點集均勻化機制

公式 (1) 蝴蝶香氣強度方程 Section III-A
f = c · Ia
  • f：蝴蝶散發之香氣強度，決定鄰近個體被吸引的強度。
  • c：感知形態係數（感覺模態），控制氣味在空間中擴散與感測靈敏度。
  • I：刺激強度，與當前候選解的適應度函數值成正比。
  • a：依賴模式的冪指數（通常介於 0.1–0.9），調節吸收程度的非線性關係。

1. 物理與生物群體行為意義

在蝴蝶優化演算法 (BOA) 中，每隻蝴蝶代表解空間中的一個候選解。適應度越高的蝴蝶會釋放越濃郁的香氣 f。當蝴蝶感應到同類散發的最強香氣時，會朝該方向進行「全域探索」飛行；反之若未感應到足夠強的香氣，則在自身鄰域進行隨機步長之「局部開發」，藉此在多峰函數地形中平衡探索與收斂。

2. 佳點集 (Best Point Set) 為何能維持種群多樣性？

傳統 BOA 採用隨機亂數初始化種群（如圖左半/紅點），容易產生局部聚集與大面積採樣空白，且每次啟動的分佈極不穩定，導致演算法早期就錯失全域最優區域而過早收斂於局部極值。

本研究引入數論「佳點集」策略構建 1000 個二維初始點（藍點）。如實驗對比所示，佳點集點位在二維單位空間 [0,1]² 內呈高度一致且均勻的網格分佈，能確保每次執行皆具備穩定的初始種群多樣性，大幅降低陷入局部最優的風險。

MODULE 02｜多模態記憶存儲與提純策略

記憶組件篩選概率、加速檢測與提純程序

公式 (4)(6)(7) 適應度概率與距離接受準則 Section III-B
p = 1 − J(xk) − J(xbest) J(xworst) − J(xbest) ，僅 p ∈ [0.5, 1] 進入評估
P(‖Di,n‖, s) = ‖Di,n‖ ‖s‖ （距離越遠，開闢新記憶槽機率越高）
  • J(xₖ)：第 k 代候選蝴蝶個體的目標代價函數值。
  • x_best / x_worst：當前種群中最佳與最差適應度個體。
  • ‖Dᵢ,ₙ‖：候選解與 Memory 中最近已存儲節點的最短距離。
  • ‖s‖：當前演化進程的空間尺度狀態參數。

1. 記憶存儲策略 (Storage Mechanism) 雙重把關

為避免多峰搜尋中僅記住單一峰值，演算法先透過適應度概率 p 將品質低於中位區間 ([0, 0.5)) 的解設為 0 並過濾；再計算候選解與現有 Memory 節點的距離概率 P(‖Dᵢ,ₙ‖, s)。當隨機數 γ 小於距離比時，代表該解位於尚未開發的新波峰，新增記憶槽 M = g + 1；若距離過近，則與最近記憶點 mₙ 進行競爭（若 J(xᵢ) < J(mₙ) 則替換更優者）。

2. 加速檢測與提純程序 (Purification Program)

加速檢測機制利用 Memory 內已存儲的高品質局部極值引導當前種群位置更新，無需反覆盲目重搜，使實驗中的目標函數在第 5 次疊代即鎖定全域最優且不再波動。同時，提純程序會週期性掃描並消除解空間中距離過近的冗餘/重複解，確保種群持續保留多峰探索多樣性，防止早熟收斂。

MODULE 03｜逐維分解與非線性局部搜尋

逐維獨立微調策略與非線性衰減軌跡解析

公式 (2) 逐維非線性局部搜尋公式 Section III-A
xj*t' = xj*t ( 1 + exp( −5 · (t / max_gen)2 + 0.3 ) · unifrnd(−1, 1) )
  • xⱼ*ᵗ：第 t 次疊代中當前最優解的第 j 個維度分量。
  • xⱼ*ᵗ'：經逐維擾動後產生的第 j 維新候選分量。
  • t / max_gen：當前疊代次數與最大疊代上限之比值，控制進程百分比。
  • unifrnd(-1, 1)：區間 [-1, 1] 均勻分佈隨機數，提供雙向對稱擾動。

1. 為何要採用「逐維搜尋 (Dimension-by-Dimension)」？

在傳統高維優化中，所有維度同時隨機變動容易產生「維度耦合退化」——某個維度變好卻被另一維度的不良步長抵消，使演算法卡在局部次優解。

逐維搜尋固定其餘維度的數值，每次僅單獨調整第 j 維並立即評估對整體目標函數的影響。這讓演算法能精準捕捉每個維度對效能的貢獻，加快當前最優解向全域最優解演化。

2. 非線性衰減軌跡的三階段物理特性

權重函數 exp(-5(t/max_gen)² + 0.3) 採用二次冪負指數曲線：在疊代初期（t/max_gen < 0.3），數值維持在 1.35 至 0.86 之間的高原區，賦予蝴蝶較寬的擾動半徑以跳脫局部陷阱；進入中期（0.3–0.7）時振幅陡降，快速鎖定全域波谷；到了末期（> 0.7）則平滑收斂至 0.009 以下，專注於最優點周邊的極微幅精細微調。

1. MBOA 如何克服傳統 SVM 參數調校瓶頸？

SVM 分類準確度高度依賴懲罰係數 c ∈ [0.01, 350] 與核函數參數 g ∈ [0.01, 100]。本研究以佳點集初始化 50 組二維 (c, g) 候選參數，結合 k 折交叉驗證計算分類誤差作為適應度，透過 MBOA 尋優後在 UCI Iris 資料集 (150 筆 / 3 類) 達成全數正確分類，解決了傳統 BOA 仍存離散誤分點之問題。

1. IIR 無限脈衝響應數位濾波器參數優化

IIR 系統辨識屬於高度非線性與多峰極值問題，傳統演算法常因陷入局部極值而使濾波器係數估測產生較大方差。MBOA 在約 50 次疊代內即完成 IIR 目標函數最小化，且重複測試之方差趨近於 0，同時在整週模糊度求解測試中以 0.014 秒單次均時達成 93.314% 高成功率。

2. 跨領域應用延伸與未來展望

除 SVM 故障分類與 IIR 濾波器外，林正旺與鄭凱文指出該框架亦可延伸至電力系統經濟調度、機械結構多目標設計、金融投資組合優化、生醫基因序列分析與醫學影像分割、交通路網流優化及環境污染物擴散模擬等複雜工程場景；未來將持續針對參數敏感性與高維計算開銷進行輕量化改進。
